# 🪙 MyToken - Simple ERC-20 Token

A basic ERC-20 token implementation built with Solidity and OpenZeppelin contracts. This project demonstrates fundamental token economics and smart contract development.

## 🌟 Features

- ✅ Standard ERC-20 functionality (transfer, approve, allowance)
- ✅ Minting capability (owner only)
- ✅ Burning mechanism
- ✅ Maximum supply cap
- ✅ Ownership controls

## 🛠️ Tech Stack

- Solidity ^0.8.20
- OpenZeppelin Contracts
- Hardhat / Foundry (for testing)
- Ethereum / EVM Compatible Chains

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Abir2021/erc20-token-learning.git

# Navigate to project directory
cd erc20-token-learning

# Install dependencies
npm install
🚀 Usage
Compile Contracts
npx hardhat compile
Run Tests
npx hardhat test
Deploy
npx hardhat run scripts/deploy.js --network <network-name>
